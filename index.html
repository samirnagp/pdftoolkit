    Questions

    Is it safe to upload my files?

    Files are sent over an encrypted connection and processed only to make your result. They are deleted right after the conversion, and any leftover is removed within minutes. Read the privacy page for details.

    Which tools work without uploading?

    Images to PDF, Merge PDF, Extract pages and Rotate PDF run entirely in your browser. The other tools need an upload.

    What is the file size limit?

    Tools that use the server accept files up to 25 MB. For bigger files, compress them first or split them with Extract pages.

    Can EasyPDF recover a forgotten password?

    No. Unlock PDF only removes a password you already know.

    My scanned PDF gives no text in Word. What now?

    Run OCR PDF first to make the text selectable, then convert the result to Word.
