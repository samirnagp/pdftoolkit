    How to use Unlock PDF

    1. Choose your protected PDF file.
    2. Type its current password (leave it empty if the file opens without one).
    3. Click Convert and download the unlocked PDF.

    Why use EasyPDF

    Removes the password

    You get a copy that opens without asking for a password.

    Removes restrictions

    Files that open freely but block printing or copying can be freed too.

    Password not stored

    The password is used only for this one step and is not kept.

    Good to know

    • This tool cannot recover a forgotten password. You need the correct password to unlock a file.
    • Use it only on files you own or have permission to change.
    • Files up to 25 MB are accepted.

    Questions about Unlock PDF

    Can you unlock a PDF if I forgot the password?

    No. EasyPDF only removes a password you already know.

    Why does it say the password is incorrect?

    Check the capital letters and spaces. Passwords are case-sensitive.

    Can I protect the file again later?

    Yes. Use Protect PDF.
