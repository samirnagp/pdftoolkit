Why some PDFs shrink a lot and others barely change

A PDF is a container. Most of its weight usually comes from images: scanned pages, photos, logos and screenshots. A 6 MB scan of a few pages can often drop to a fraction of that size. A PDF that is mostly text is already small, so there is little to remove. If we cannot make a file smaller, you get your original back, so a compressed result is never bigger than what you uploaded.

How to get a PDF under a size limit

  1. Try Balanced first. If the file is still too big, run it again on Smallest file.
  2. Remove pages you don’t need. Use Extract Pages to keep only the pages the form asks for.
  3. Rebuild from smaller images. If your PDF comes from phone photos, make it again with Images to PDF or Scan to PDF using lower-resolution pictures.
  4. Split a very large file. Files over 25 MB can be split, compressed in parts, then joined with Merge PDF.
  5. For a strict 10, 50 or 100 KB limit, use www.easypdf.website.

Compress PDF: frequently asked questions

Can I compress a PDF to exactly 50 KB or 100 KB here?

This page offers three general levels and cannot promise an exact size. For a target such as 10 KB, 50 KB or 100 KB, use www.easypdf.website.

Will compressing change my text or layout?

No. Compression mainly recompresses images, so text and layout stay the same. Images can look softer at the Smallest level.

Why is my compressed PDF almost the same size?

If the file is mostly text, or was already compressed, there is little left to remove. You then receive your original file.

Is there a file size limit?

Yes. This tool accepts files up to 25 MB. For larger files, split them first, then compress each part.

Is my file kept on your server?

No. It is deleted right after the result is sent, and any leftover is removed within minutes.

Can I compress a scanned PDF?

Yes. Scans are image-heavy, so they usually shrink the most. To also make the text searchable, run OCR PDF.
