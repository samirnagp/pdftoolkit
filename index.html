    Step-by-step deployment

    This site is one static HTML file, so hosting is free and takes minutes.

      Adding server-side tools later (PDF → Word, Office → PDF, OCR)
      1. Create a small API (Node/Express or Python/FastAPI) that wraps LibreOffice (soffice --headless --convert-to pdf) or Poppler/Tesseract.
      2. Package it with a Dockerfile and deploy to Render, Railway or Google Cloud Run.
      3. Call it from the page with fetch('/api/convert', {method:'POST', body: formData}).
      4. Add file-size limits, auto-delete uploads after a few minutes, and rate limiting.
