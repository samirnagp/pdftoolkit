    How to use Repair PDF

    1. Choose the damaged PDF.
    2. Click Repair PDF.
    3. Download the repaired copy and check that it opens.

    Why use EasyPDF

    Two repair methods

    The file is rebuilt first, and if that fails, it is re-printed into a fresh PDF.

    Fixes common damage

    Cut-off downloads, broken page tables and damaged headers are often fixable.

    Deleted after repair

    Your file is removed from our server as soon as the repaired copy is sent.

    Good to know

    • Repair can only recover what is still in the file. Badly damaged files may lose pages or images.
    • Password-protected files must be unlocked first with Unlock PDF.
    • Keep the original file, and check the repaired copy before you rely on it.
    • Files up to 25 MB are accepted.

    Questions about Repair PDF

    Will I get everything back?

    Not always. If part of the file is missing, that part can’t be recovered. Often the pages that are still there are saved.

    What if the repair fails?

    Try downloading or exporting the file again from its source, or ask the sender for another copy.

    Does repair remove a password?

    No. Use Unlock PDF for that.
