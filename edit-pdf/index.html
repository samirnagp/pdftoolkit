Good to know

  • EasyPDF adds new items on top of the page. It can’t change the text that is already in the PDF.
  • Cover (a white box) hides what is under it only visually. The original text can still be inside the file, so don’t use it to hide sensitive information.
  • Text supports Latin letters, numbers and common symbols. Other alphabets, such as Hindi, are not supported yet.
  • To rotate pages, use Rotate PDF first. Password-protected PDFs need Unlock PDF first.

Questions about Edit PDF

Can I change the existing text in the PDF?

No. The editor adds new text, drawings and images on top. To change the original text, convert the PDF to Word, edit it there and convert it back.

Is the white cover safe for hiding private information?

No. It only covers the content visually. The hidden text can still be in the file.

Can I sign a PDF?

Yes. Use Draw to sign with your finger or mouse, or add a picture of your signature with Image.

Is my PDF uploaded?

No. Editing runs entirely in your browser.
